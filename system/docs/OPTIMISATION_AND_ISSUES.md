# 优化结果与剩余问题

采用父版仍为OPT35a/V2A。下面保留实验的实际资格，目标是让后续工作解决已知最大项，避免重复无效比较。

当前开发硬件已选AB1 OPT38+v5，正式父版不移动。v5独立诊断软件/C/B241.449/31.580/0ms达到旧目标；v5对F05两窗公平收益仍INCONCLUSIVE。AB1在同一v5软件下20图比较有效，core887.999602→438.384590→888.105542ms，下降50.632344%，wait646.406→197.531ms，非wait约241.7ms不变。此项只签开发硬件采用，不签正式PL/CPU加速比。

AB2/3软件通过但首个组合PL诊断第0层Y比较FAIL、41文件回收/回退PASS，先定位再谈采用；AB5尚无本机完整结果。下一预算包括PS/量化和内存组织，不能重复重写已做的v5热路径。源码与最新原始回执见[V5/AB](V5_AB_HANDOFF.md)和[10月9日汇总](../evidence/latest/runtime_progress_20261009.json)。
