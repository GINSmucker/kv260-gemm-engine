# 运行时与设备生命周期

H576 的模型插件与唯一硬件控制进程通过固定共享缓冲交付数据。权重在初始化时装载，输入输出按同步顺序复用。模型插件直接量化写入输入，读取整数输出并完成后处理；owner 管理设备、缓存同步和完成状态。

[冻结运行源码](runtime/h576/)保持原字节身份。大型模型和配对运行产物通过[按需资产](../docs/locks/ASSETS.lock.json)取得，资产中保留的历史启动绑定不能直接在新窗口重放。维护者必须重新确认启动、驱动、平台、owner 与模型一致。

完成状态未知时，不重放原请求、不强杀控制者、不释放 DMA 使用中的资源。证明计算与 AXI 静止后才能退出与回退。停止网页服务不等于硬件已经静止。

[工作台指南](../docs/workbench.md)说明存档展示与真实图片推理。网页能力来自板端当前健康状态，不负责底层加载、复位或系统改动。旧默认平台与运行配置保留独立用途。
