# FPGA 计算引擎

当前 H576 引擎采用单一计算单元、512 MAC、125 MHz 和三路 128 位外部数据口，负责完整矩阵乘法与 K 归约。qkv、fc1 和 fc2 共三十六层进入 PL；模型其他计算保留。

输入输出沿紧凑矩阵布局传输，输出组织提供连续供数，避免只扩大总线参数却没有内部数据供给。形状、平台标识、运行包和模型必须同时匹配。计算周期、HLS 时序估计、布局布线时序和完整交付时间各自有独立含义。

[当前引擎实现](h576/)保留冻结源码，[运行身份](../docs/locks/H576_PACKAGE.lock.json)绑定配对产物。旧默认计算核、未缩宽 OPT45 和资源候选维持独立用途，不能替代当前模型的硬件。

硬件接口、生命周期和验收范围分别见[公共接口](../docs/interface.md)与[验证说明](../docs/verification.md)。硬件、模型和线程保持冻结；取得源码不代表授权新的板卡操作。
