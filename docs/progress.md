# 当前系统与成果

## 模型和固定分工

当前研究交付为 H576 紧凑模型的第一轮冻结训练候选。十二个块的 MLP 隐藏宽度为 576，attention、残差、归一化和分类头等完整计算保留。四十九个线性层采用初始化时确定的路由：qkv、fc1、fc2 共三十六层执行于 PL，proj 和 head 共十三层执行于 CPU。运行中不试跑选路，也不在失败后静默回退至 CPU。

模型使用 Dense W8A8。有符号八位权重与激活进入硬件，完整归约输出三十二位整数；处理器反量化、加偏置并继续后续节点。2:4 剪枝研究不代表该路径具备稀疏硬件能力。

## 数据与执行职责

本机工作台负责展示、请求转发和下载；板端服务负责图片预处理与完整模型调用。模型插件负责量化、固定分工和结果消费，唯一硬件控制进程负责设备所有权、缓存同步、启动与静止确认。

共享输入输出沿同步调用顺序复用，权重一次装载后按固定偏移使用。大块矩阵通过共享内存交付，socket 承担控制消息。收发先立即尝试，仅在暂不可用时等待。执行状态未知时不重放已提交任务，不释放仍被硬件使用的缓冲。

PS 保持四线程。QKV 直接生成后续布局；GELU 保留原生 Erf，外围算术按既定浮点舍入顺序融合，并将行最大值交给 fc2 量化，减少重复扫描。K 转置和现有 attention 内核保留。

## 实测结果

硬件为 512 MAC、125 MHz、128 位通路的单引擎。两轮完整交付中位数为 142.778 和 142.682 ms，p95 为 144.310 和 144.194 ms。相对原 ARM FP32 中位数加速约为 2.295 和 2.294 倍，相对同候选 W8A8 数值语义参考约为 2.070 倍。该结果衡量整个方案，不能全部归因于 MAC 阵列。

真实 PL 完成既有 3,925 张图像验证，Top1 为 3,039，Top5 为 3,729；原 FP32 为 2,978 和 3,717。五百张子集对应为 390 和 480，原模型为 386 和 475。两组并非独立数据集，不能相加。相对原 FP32 的 Top1 满足下降不超过一个百分点的预算。

同 ARM 候选与 PL 的全部 3,925,000 个 logits 一致，无缺失或剔除。跨主机 W8 逐值差异仍为失败，不能由 Top1 通过覆盖。独立有限稳定性覆盖五千次推理和十轮正式加载回退，资源趋势通过；二十张公开图片重复使用，不代表五千张质量覆盖或无限运行保证。

## 展示与交付

真实 Chrome 已完成内置图片三后端推理、性能对比、五类路由和 JSON／CSV 下载。成果总览、双曲线和四十九层路由图另有存档浏览验证；新展示层的实时板端全链路没有重新运行，不把旧证据转签为新界面全部通过。

正式发布仍需联合签署、保留质量集的启用决策、跨主机数值差异的合同解释，以及本机图片自动上传路径的补验。清洁复部署依赖既有 SDK 和推理环境，不等于从全新操作系统重建。模型与硬件冻结，两千张质量保留集未使用。

旧默认开发配置、正式资格参考和资源候选仍可供各自用途，不承担当前 H576 的结果。实际硬件与质量实验日期为十月十六日，Chrome 图片链路为十月十七日；文档整理不产生新板测结论。
