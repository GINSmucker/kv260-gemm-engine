# 仓库阅读与协作入口

当前完整 H576 成果位于[交付入口](https://github.com/GINSmucker/kv260-gemm-engine/tree/codex/team-handoff-20261007)，提供系统总结、Archify 架构说明、工作台指南、源码与公开验证记录。模型与硬件保持冻结，研究交付不替代联合正式发布资格。

团队仓库的默认首页提供成果展示与完整交付导航；个人仓库的默认分支直接承载完整交付。两仓库维持独立的版本历史和各自的资产下载地址，不自动双向同步。

旧默认开发配置、未缩宽 OPT45、资源候选与正式资格参考仍有独立用途。取得源码、运行包或网页不构成新的板卡操作授权。

功能变更通过独立评审合入相应目标分支。冻结标签与原始回执不移动，不强制推送，不用资料更新改变模型、硬件或验收资格。
