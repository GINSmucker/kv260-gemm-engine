# 证据与验收范围

各项结论只适用于对应候选、环境、输入和计时边界。冻结运行包包含八十四项载荷；源码、配对硬件、模型和结果通过身份摘要绑定。发布整理保留公开原始回执的字节身份，不改写原签署，也不把整理日期作为实验日期。

## 两类对照

完整性能从浮点输入张量进入运行器开始，到浮点 logits 返回为止，不包含初始化、图片预处理、硬件加载、序列化和验算。原 FP32 对照体现整个方案收益；同 H576 W8A8 对照缩小模型差异，但 CPU 执行仍是语义参考，不是优化后的 INT8 内核。不能把该倍数解释为硬件单独的加速率。

质量对照使用原 FP32 与冻结候选。既有完整集只涵盖十类图像，五百张是其子集，因此不形成两次独立质量证明，也不证明完整 ImageNet 泛化。模型选择数据、质量评估数据与有限稳定性重复图片各有用途，样本数不能混用。

## 记录完整性

公开交付附有[结果索引](../results/model_planning/h576_closeout_20261016_01/delivery_index.json)、[冻结身份](locks/H576_PACKAGE.lock.json)与[源码映射](locks/H576_SOURCE_MAP.json)。索引收录维持原字节的公开摘要和浏览器结果，完整原始运行记录由项目维护者保存；它不是全部原始日志的镜像。所引用的 C 证据为公开回执，不包含私有留出种子或向量。

失败记录包括性能比较中的请求标识问题、加载前磁盘门禁失败和浏览器控制失败。后续成功仅覆盖实际补验范围，不删除或重标原失败。五千次连续运行使用二十张公开图片；资源有限趋势不推导为永久无泄漏。

## 重现和未覆盖条件

本机软件检查核对源码清单、语法、模块导入、界面与请求合同，不接触 FPGA。冻结运行资产提供完整模型、配对产物与公开输入，但历史启动身份不可直接在新板卡窗口重放。新部署必须重新绑定当前启动、owner 和实际设备状态。

既有清洁复部署复用了板端 SDK、ONNX Runtime 与预处理环境。全新系统重建、永久 AXI 故障恢复、无限期可靠性、高地址实测覆盖和取消延迟上界仍不在当前证明范围内。任何模型、驱动、平台或数值顺序变化，都不能直接继承原验收资格。
