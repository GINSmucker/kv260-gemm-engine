# 有效设计与待核实问题

当前研究设计为OPT45/X128/Y768/QuantQKV、固定W BO及四线程和固定36层共享交付。完整FP32边界与无诊断整图有数值和测量证据；当前分位数见[progress](../progress.md)。默认运行包仍为OPT38。

需要解释的现象：亲和性p50/p99并非两轮一致改善；200次有界运行不能证明长期资源与稀有慢图上限。独立X/Y阶段与诊断扰动未测，AR至首R/末W至B未报告，不能把边界差异全部归因于某个内部阶段或DDR。

必要cache sync和完整Done/排空不能删除。W在owner初始化装载/同步固定BO，PL每层仍读取W；额外HP、Stream、第二队列或双缓冲未实施。普通libm GELU及1/2线程数值FAIL，不能用于等价配置。

永久AXI故障恢复、overlay属性生命周期与长期反复切换尚未证明；正式独立C、PL500/full质量、独立长稳和发布签署NOT RUN。可靠小收益依据完整固定样本判断，无机械5%阈值；不得过滤慢样本。证据范围见[verification](../verification.md)。
