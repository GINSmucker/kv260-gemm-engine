# v1 结果与历史范围

本分支活跃核是历史 Dense v0.2；当前源身份见根 `VERSION.json`。本次活跃目录的新 HLS/RTL/板端性能和模型精度均为 **NOT RUN**，不填入其他核的毫秒数。

`versions/` 保留先前的三阶段归档结果和同权重 OPT50 单对样本，其候选名、源码哈希及测量范围保持原样；不构成当前 v1 的结果。`summary.csv` 当前只有表头，不是已有板测数据。

以后在本版产生结果时，每条记录须绑定来源提交、活跃源码 SHA、工具/时钟、M/N/K、输入身份与计时边界。原生 C++、HLS 估计、RTL 周期和板端计时分别报告；大型日志、IP、`.xclbin` 与 FPGA 二进制放 Release，并在 Git 留可核验索引。
